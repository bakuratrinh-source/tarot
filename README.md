# Tarot Reading App

MVP web app for a real-world-style Tarot reading flow.

## Current scope
- Choose a Tarot deck
- Select a spread
- Shuffle and draw cards
- Reveal cards one by one
- Record position and reversed state
- Generate a structured reading summary
- Copy the summary for AI interpretation
- Reset and start a new reading

## Next phases
1. Add full deck artwork and metadata
2. Add more spreads
3. Add reading history
4. Add optional AI interpretation endpoint
5. Add mobile-first polish and animations
6. Add automated QA and deployment

## Development
Run with any static web server or open index.html in a browser.
